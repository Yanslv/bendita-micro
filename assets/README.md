# Ativos de referência — Bendita Micro / Ioná Victório

Este pacote contém 59 imagens localizadas no HTML capturado do perfil público do Instagram e dos destaques navegados no My Browser em 18/09/2026.

Os arquivos foram organizados para análise e prototipação. Eles não são automaticamente licenciados para publicação comercial. O campo `usage_status` do `manifest.csv` está marcado como `reference_only_pending_authorization`.

Antes de usar qualquer imagem no site da Bendita Micro, solicitar à Ioná:

1. o arquivo original em alta resolução;
2. confirmação de que a imagem pode ser utilizada no site;
3. autorização para imagens de clientes e resultados;
4. contexto e legenda aprovados para antes/depois ou cicatrização;
5. o logo original em PNG/SVG, pois não foi encontrado um arquivo de logo separado.

O `image_inventory.csv` contém formato, dimensões e tamanho dos arquivos. O `manifest.csv` contém a URL de origem, o HTML de origem, o status do download e o status de uso.

As URLs de CDN do Instagram são temporárias e podem expirar. O pacote não deve ser tratado como backup permanente do Instagram.
